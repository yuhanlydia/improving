Use the prompts to redesign composition, then render scientific data with a plotting tool. There are exactly three alternatives for each figure. Option 1 matches the delivered PDF. The separate files in `figure-prompts/` are independently reusable.

All metric labels describe normalized-AST richness. They do not claim semantic strategy labels. Richness is expected distinct-class count (rarefaction), not task pass rate; correct-conditioned richness fixes the number of correct samples. Correctness on MBPP means passing the supplied program tests.
